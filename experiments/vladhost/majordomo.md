# Majordomo как ориентир для Vladhost

Дата сбора: 24.09.2026. Источники — справка и статьи majordomo.ru, страницы тарифов, описание мобильного приложения, обзоры хостингов (список в конце).
Что не удалось выяснить (в открытых материалах нет): лимиты по процессам/памяти/inode, детали SSH-ограничений, webmail и протоколы почты. Такие места помечены «нет данных».
Сам интерфейс панели (внешний вид) я не видел, только описание структуры.

## 1. Что такое Majordomo

- Российский хостинг с 2000 года, собственная панель HMS («Hosting Management System»), полностью на русском. Серверы в России.
- Услуги: виртуальный хостинг, VPS/VDS, выделенные серверы, регистрация доменов (500+ зон), корпоративная почта, SSL, конструктор сайтов с ИИ, защита почты.
- Тарифы: виртуальный хостинг от ~99–219 ₽/мес, VPS от ~419–439 ₽/мес. «Старт»: 15 ГБ SSD, 10 сайтов, 2 БД, ∞ почтовых ящиков. Профессиональные: 30–55 ГБ, ∞ сайтов, ∞ БД, ∞ ящиков.
- Тестовый период 7 дней, тестовый домен третьего уровня для проверки без покупки.
- Поддержка 24/7. Бесплатный перенос сайта. Партнёрская программа и акции видны прямо в панели.
- Мобильное приложение (Android): вся панель в телефоне.

## 2. Структура их панели

Панель — единый кабинет аккаунта. Разделы:

| Раздел | Что внутри |
|---|---|
| Сводка | диск (занято/свободно), тариф, баланс, ближайшие платежи |
| Сайты | список сайтов; у каждого — домены и алиасы, версия PHP, корневая папка, параметры веб-сервера, логи, архив сайта, установка CMS |
| Домены | регистрация, перенос, подключение чужого домена, автопродление, редактор DNS-зоны, поддомены, профили владельцев (whois), SSL |
| Почта | ящики на домене (бесплатно, без лимита числа), настройки безопасности |
| Базы данных | MySQL: базы, пользователи, доступ по IP, смена пароля, phpMyAdmin |
| Доступ | FTP-аккаунты, SSH (ключи, WebSSH в браузере) |
| Резервные копии | восстановление сайта/БД/файлов на выбранную дату |
| Cron | планировщик задач |
| Статистика | посещаемость сайтов, нагрузка на сервер |
| Финансы | баланс, пополнение, история платежей, абонемент |
| Поддержка | обращения в техподдержку, база знаний |
| Партнёрка | акции, бонусы |

Вывод по устройству: **список ресурсов → выбор → кабинет ресурса** (то, что мы уже сделали для сайта), плюс аккаунтные разделы отдельно.

## 3. Функции по областям

### Сайты
- Несколько сайтов на аккаунте; у сайта основной домен + алиасы.
- Версия PHP на выбор (5.2–8.3) с пометкой уровня безопасности; переключатели модулей (mbstring, allow_url_fopen).
- Корневая директория сайта задаётся.
- Расширения файлов, отдаваемых nginx напрямую; CGI (Perl, C, shell), SSI.
- Поддомены создаются как директории.
- Логи доступа и ошибок в каталоге `logs/`.
- Скачать архив сайта (файлы + БД).
- Установка CMS в один клик (WordPress, Joomla, OpenCart, Moodle, 1С-Битрикс): создаётся БД, таблицы, админ, данные приходят на email.
- Отдельные сервисы: Redis, Memcached, uWSGI (Python/Ruby), Node.
- Ограничение доступа по паролю, `.htaccess`.

### Домены и DNS
- Регистрация/перенос/продление, автопродление, профили владельцев.
- Свои домены: подключение через NS Majordomo (нужно для их Let's Encrypt).
- Редактор DNS: A, AAAA, MX, CNAME, TXT (SPF), SRV.
- Подсказка «изменения DNS применяются 4–48 часов, обычно до 12».
- Тестовый домен третьего уровня и предупреждение, что по IP сертификат не выпустить.
- Переадресация домена (доп. услуга).

### SSL
- Бесплатный Let's Encrypt в 2 клика, автопродление.
- Платные сертификаты разных уровней (DV/OV/EV, wildcard).

### Почта
- Неограниченно ящиков на домене, оплата по объёму, а не по числу.
- SSL/TLS, DKIM, DMARC, SPF (через TXT).
- Защита от спама и вирусов (платная услуга).
- Webmail, IMAP/POP3, пересылки, автоответчики, алиасы — в открытых материалах нет данных, но это стандарт.

### Базы данных
- MySQL: создание/удаление баз и пользователей, один «суперпользователь» на все базы или отдельные.
- Доступ снаружи по разрешённым IP.
- phpMyAdmin.

### Доступ
- FTP: несколько аккаунтов; доп. FTP-доступ платный (3 ₽/день).
- SSH по ключам (генерация и скачивание пары в панели), WebSSH в браузере.

### Резервные копии
- Ежедневные, хранятся 7 суток, бесплатно.
- Расширенное копирование: 30 дней на выделенном сервере.
- Восстановление в 4 шага: объект → дата → подтверждение → ожидание.

### Безопасность
- DDoS-защита, лечение/сканирование сайта, онлайн-мониторинг, SEO-аудит (доп. сервисы).
- SMS-уведомления.

### Финансы и прочее
- Баланс, абонемент, смена тарифа, история платежей.
- Партнёрская программа.
- Конструктор сайтов.
- Мобильное приложение.

## 5. Что сделать, чтобы было не хуже

Ниже приоритеты для бесплатного хостинга. Пункты, которые бессмысленны без денег (регистрация доменов, платные SSL, партнёрка), вынесены отдельно.

### Уровень 1: без этого панель выглядит неполной
1. **Сводка аккаунта.** Диск, число сайтов, последние события, статус HTTPS всех сайтов, быстрые действия. Часть уже есть в «Обзоре», доделать под данные из кабинета.
2. **Логи сайта.** Доступ и ошибки шлюза, просмотр и скачивание, фильтр по коду ответа и дате. Данные уже проходят через `vladhost web`, нужно писать в файл с ротацией.
3. **Статистика.** Запросы, уникальные IP, топ страниц, коды ответов, трафик по дням (по логам, без внешних сервисов).
4. **Несколько FTP-аккаунтов на сайт** (план 5.2): свой логин/пароль, ограничение папкой, отключение отдельного аккаунта.
5. **Резервные копии.** Ежедневный снимок, хранение 7 дней, восстановление на дату из панели, скачивание архива сайта. Для статики дёшево (hardlink/rsync-снимки).
6. **Поддомены и алиасы сайта.** Дополнительные имена `*.user.vladinc.ru` и подпапки-как-поддомены.
7. **Настройки сайта:** индексный файл, корневая подпапка (`public/` или другая), включение/выключение листинга каталогов, страницы ошибок из панели, принудительный HTTPS и `www`-редирект.
8. **Управление SSL** (план §15): статус, дата окончания, принудительное перевыпуск, сертификаты своих доменов.
9. **Уведомления по почте** (нужно SPF/DKIM в exim): подтверждение почты, сброс пароля, сообщения о сбое сертификата и о заканчивающемся месте.

### Уровень 2: то, за что Majordomo и держат клиентов
10. **Базы данных** (PostgreSQL и/или MySQL/MariaDB): создать/удалить базу, пользователи, пароль, внешний доступ по IP, веб-клиент (Adminer вместо phpMyAdmin).
11. **Cron** для динамических сайтов (планировщик задач с логом запусков).
12. **Динамика:** PHP-FPM с выбором версии, затем Node/Python в Docker (план фаза 6). Без этого CMS не поставить.
13. **Установка CMS в один клик** (WordPress, Joomla и т. д.): зависит от пунктов 10 и 12.
14. **SSH и WebSSH:** доступ по ключам в chroot/контейнере, генерация ключа в панели.
15. **Почта** (план §13): ящики на своих доменах, webmail, IMAP/SMTP, DKIM/SPF/DMARC подсказки, пересылки, автоответчик.
16. **Редактор DNS.** Понадобится только если заведём свои NS; пока достаточно инструкции по A-записи.

### Уровень 3: удобство и доверие
17. **Тикеты/обратная связь** и база знаний (справка на ru/it внутри панели).
18. **Журнал действий аккаунта:** входы, смена пароля, выдача FTP, деплои (с IP и временем).
19. **2FA (TOTP)** и список активных сессий с кнопкой «завершить».
20. **API-токены и CLI** для деплоя из CI (`vladhost deploy ./dist`), вебхук/GitHub Action.
21. **Импорт сайта:** скачать zip/tar с URL, перенос с другого хостинга (аналог «бесплатный перенос»).
22. **Статус-страница** и мониторинг доступности своего сайта (uptime-проверка, письмо при падении).
23. **Мобильное приложение или PWA.** Быстрее всего — PWA: манифест, иконки, работа как приложение.
24. **Тёмная/светлая тема** и настройки профиля (аватар, часовой пояс).
25. **Админка:** пользователи, лимиты, блокировки, инвайты, аудит; жалобы на контент (abuse) и антивирус-проверка загрузок.

### Что копировать не нужно
- Регистрация и перенос доменов, платные сертификаты, баланс и оплата, партнёрская программа: у нас бесплатный хостинг по приглашениям.
- Регистрация и продление доменов в зонах: возможно позже через партнёрский API, пока вне плана.

## 6. Предлагаемый порядок работ

1. Настройки сайта (7) + поддомены/алиасы (6): быстро, опирается на готовый шлюз.
2. Логи (2) и статистика (3): данные уже в шлюзе.
3. Несколько FTP-аккаунтов (4).
4. Резервные копии и архив сайта (5).
5. SSL-раздел (8) и журнал действий (18), 2FA (19).
6. Почта: подтверждение и уведомления (9), затем ящики и webmail (15).
7. Базы данных (10) → cron (11) → PHP/Docker (12) → CMS в один клик (13) → SSH (14).
8. API/CLI (20), импорт (21), мониторинг (22), PWA (23).

Каждый пункт: сразу на ru и it, ключи i18n в оба каталога, тесты соразмерно правке, после деплоя проверка только curl.
