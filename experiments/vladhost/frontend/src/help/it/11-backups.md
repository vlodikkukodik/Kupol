## Come funziona

Ogni giorno il pannello crea uno snapshot dei file del sito e lo conserva per 7 giorni. L'elenco delle copie è nella scheda «Copie di sicurezza» del sito.

## Cosa si può fare

- **Creare una copia** subito — prima di modifiche rischiose.
- **Ripristinare** i file da una copia della data scelta. I file attuali verranno sostituiti, quindi crea prima una copia recente.
- **Scaricare una copia** o **tutto il sito come archivio** — ad esempio per trasferirlo su un altro hosting.

## Da sapere

- Le copie contengono i file del sito. **I database non ne fanno parte**: esportali separatamente con il client web del database.
- Vengono conservate le copie degli ultimi 7 giorni: quelle più vecchie vengono eliminate automaticamente.
