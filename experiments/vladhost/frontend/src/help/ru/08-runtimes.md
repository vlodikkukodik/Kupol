## Выбор среды

Откройте сайт → вкладка «Среда» и выберите:

- **Статика** — файлы отдаются как есть.
- **PHP** — скрипты `.php` выполняются в отдельном пуле сайта, версию можно выбрать. Работает `.htaccess` (например, перенаправление на `index.php`).
- **Node.js** и **Python** — ваше приложение запускается как служба. Панель передаёт порт в переменной `PORT`; слушать нужно адрес `127.0.0.1`. Все запросы к сайту идут в приложение.

## Команда запуска (Node.js и Python)

Укажите одну строку команды, например:

```
node server.js
```

Команда выполняется в папке сайта. После изменения кода нажмите «Перезапустить».

## Журнал и состояние

На вкладке «Среда» видны состояние приложения и последние строки журнала. Ошибки PHP пишутся в журнал сайта.

## Безопасность

Каждый сайт работает под своим системным пользователем и видит только свою папку. Внутренние сети недоступны, выполнение системных команд из PHP отключено.
