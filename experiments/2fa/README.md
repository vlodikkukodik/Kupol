# 2FA — TOTP-коды на PHP + MySQL

Сайт, который создаёт и хранит секреты 2FA на сервере (в MySQL) и выдаёт настоящие
TOTP-коды (RFC 6238). В браузере секретов нет — он получает только текущий код.

## Запуск

1. `cp .env.example .env` и заполните: доступ к MySQL, `ADMIN_USER`/`ADMIN_PASSWORD`, `APP_KEY`
   (`php -r "echo bin2hex(random_bytes(32));"`).
2. Таблицы создаются автоматически при первом обращении (нужна пустая БД и права CREATE).
3. Веб-корень — папка `public/`. Локально: `php -S 127.0.0.1:8080 -t public`.
4. `.env` держите вне веб-корня и вне git (уже в `.gitignore`).

## Как это устроено

- Секреты шифруются AES-256-GCM ключом из `APP_KEY` перед записью в БД. Утечка дампа БД без `.env` секретов не раскрывает.
- Вход: логин/пароль из `.env`, CSRF-токены, ограничение 5 неудачных попыток за 15 минут на IP.
- Можно ввести свой base32-секрет, вставить `otpauth://` ссылку или оставить поле пустым — секрет создастся случайно (показывается один раз).
- Поддерживаются SHA1/SHA256/SHA512, 6–8 цифр, период 10–120 с.
- Коды считает сервер (`?a=codes`), страница только обновляет их по таймеру.
- Не меняйте `APP_KEY` после сохранения секретов — их нельзя будет расшифровать.
- Для боевого использования включите HTTPS.
